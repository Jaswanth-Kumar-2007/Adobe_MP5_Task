## Directory guide

- `data/raw/`: untouched source PDFs read by the automatic extractors.
- `data/extracted/`: primary CSVs produced by the enabled extraction run.
- `data/extracted/review/`: review candidates and source evidence retained for manual inspection.
- `data/manual/`: legacy manually curated CSVs, including `resources.csv`; not consumed by `run_pipeline.py`.
- `data/processed/normalized/`: normalized copies used by validation, relationships, chunking, and export.
- `data/processed/relationships/`: generated course relationship JSON.
- `data/processed/chunks/`: created by chunking but currently contains only `.gitkeep`; chunks are exported to `output/chunks.jsonl`.
- `extractors/`: source-specific PDF parsers and the derived topics/skills generator.
- `pipeline/`: downstream normalization, validation, relationship, chunking, export, and reporting code.
- `validators/`: independent validation utilities.
- `output/`: final JSON, JSONL, and chunk JSONL exports.
- `reports/`: generated data-quality reports, execution logs, and validation issue CSVs.
